กฎการรับใบเตือน (PENALTY SYSTEM)

กฎระเบียบภายในแก๊ง BLACK KINGDOM หากฝ่าฝืนจะได้รับบทลงโทษตามที่กำหนด

1. สมาชิกต้องฟังคำสั่งจากหลีดรองหลีด
🟨 ใบเหลือง / 🟧 ใบส้ม
2. นำพาความเดือดร้อนมาให้ตระกูลโดยไม่รับผิดชอบ
🟥 ใบแดง / ⬛ ใบดำ
3. นำพาผู้อื่นหรือคนภายนอกเข้าดิสโดยไม่ได้อนุญาต
🟨 ใบเหลือง
4. นำสกินแก๊งไปขายหรือจำหน่ายให้ผู้อื่น
🟥 ใบแดง / ⬛ ใบดำ
5. เล่นโปรเล่นมอด
⬛ ใบดำ (ปลดออก)
6. ด่าเรื้อนไปด่าแก๊งอื่น
🟧 ใบส้ม
7. ไม่เชื่อฟังผู้คุมสายสตอรี่
🟨 ใบเหลือง / 🟧 ใบส้ม
8. ไม่มีความรับผิดชอบ
🟨 ใบเหลือง
9. สอบสวนแล้วให้การเท็จ
🟥 ใบแดง
10. แจ้งลาโดยสาเหตุไม่ชัดเจน
🟨 ใบเหลือง
11. ส่งลิ้งค์ดิสมั่ว
🟨 ใบเหลือง
12. ด่าบุพการี
🟧 ใบส้ม
13. ฝ่าฝืนกฎคูลดาวน์พบเจอสถานที่ต้องห้าม
🚫 โดนโทษ x2
14. นำข้อมูลภายในแก๊งไปเผยแพร่
🟥 ใบแดง / ⬛ ใบดำ
15. ไม่จ่ายเงินแก๊ง
🟨 ใบเหลือง
16. เข้าร่วมยึดคุก/กิจกรรม แล้วร่วมมือกับแก๊งอื่น
🟥🟥🟥 โดนใบแดง 3 ใบ❗
17. มีปัญหา เรื้อน หรือทำร้ายพันธมิตร
⬛⬛⬛ โดนใบดำ 3 ใบ❗❗❗
18. คนในแก๊งทำโพเทคแก๊งแตก
🟡🟡🟡 ใบเหลือง 3 ใบ + เสียค่าโพเทค

กฎการเล่นกิจกรรมแก๊ง

ข้อบังคับในการลงเล่นกิจกรรม AirDrop, ยึดคุก และ วอยึดโซน

1. กฎการเล่น AirDrop (แอร์ดรอป แก๊งค์)

เวลา: 13:00 / 18:00 / 21:00
  • ห้ามมีสตอรี่กันโดยเด็ดขาดในเวลากิจกรรม [ บังคับ ]
  • ห้าม Toxic หรือ บัพกันแรงเกินไป
  • สามารถใช้ AED ใน AirDrop ได้
  • สามารถใช้ Bandage ในการ Heal ตัวเองได้
  • ไม่สามารถใช้อีโมได้ เนื่องจากเป็นการเอาเปรียบ MB / มือถือ [ บังคับ ]
  • ห้ามใช้ MOD / โปรแกรมโกง หรือสิ่งที่จะทำให้ได้เปรียบฝั่งตรงข้าม [ โทษใบแดง / บังคับ ]
  • สามารถใช้เกราะได้ตามปกติ
  • ข้อห้ามสำคัญ: ห้ามตีก่อน 5 นาที เด็ดขาด!

2. กฎยึดคุก

เวลาเริ่ม: 20:00 น.
  • 1. ต้องตีกันให้ตายจนเหลือเพียง 1 แก๊ง ถึงจะเก็บจุดยึดคุกได้ (ทำบัคเก็บโดนใบแดง 🟥 / เก็บตอนผู้เล่นยังตายไม่หมดโดนใบส้ม 🟧)
  • 2. ห้ามร่วมมือกับแก๊งอื่น [ โดนใบส้มทั้งแก๊ง 🟧 ]
  • 3. ห้ามอีโม [ โดนใบแดง 🟥 ]
  • 4. ห้ามนำเรื่องกิจกรรมมาเป็นสตอรี่ความแค้นส่วนตัว [ โดนใบเหลือง 🟨 ]
  • 5. ห้ามใส่สกินเด็ก, สกินตัวเล็ก [ โดนใบส้ม 🟧 ]
  • 6. ห้าม Toxic หรือบัพกันแรงเกินไป [ โดนใบแดง 🟥 ]
  • 7. ห้ามใช้มอด โปร หรือทำบัค [ โดนใบแดง 🟥 ]
  • 8. ห้ามอุ้ม กักศพ
  • 9. ห้ามบู๊ด เปิดซาวด์ก่อกวน [ โดนใบเหลือง 🟨 ]
  • 10. ห้ามดักจุดเกิด [ โดนใบเหลือง 🟨 ]
  • 11. ห้ามใส่แฟชั่นเล่นกิจกรรม

3. กฎวอยึดโซน

เวลา: 21:30 - 22:30 น.
  • ห้าม DB หรือ ขับรถชนในโซน [ โดนใบเหลือง 🟨 ]
  • ห้ามตีนอกสถานที่ [ โดนใบส้ม 🟧 ]
  • ห้ามอุ้มศพกักศพ [ โดนใบส้ม 🟧 ]
  • ห้ามใส่สกินเด็กเล่นกิจกรรม [ โดนใบส้ม 🟧 ]
  • ห้ามเล่นโปรมอด [ โดนใบแดง 🟥 ]
  • ห้ามอีโม [ โดนใบแดง 🟥 ]
  • ห้าม Toxic หรือบัพแรงเกินไป [ โดนใบแดง 🟥 ]
กฎวอยึดโซนเพิ่มเติม:
• การเล่นวอยึดโซนจะต้องต่อสู้ ภายในวงเท่านั้น ห้ามออกจากวง เพื่อไปปั๊มยา, ชุบชีวิต หรืออุ้มเพื่อนไปชุบ หรือทำกิจกรรมอื่นใดแล้วกลับเข้ามาวงใหม่
• หากไม่สามารถต่อสู้ต่อได้ หรือประสงค์จะถอนตัว ให้ขับรถออกจากพื้นที่นั้นเพื่อยอมแพ้
• ห้ามตีนอกบริเวณวงกิจกรรมเด็ดขาด ต้องตีกันในวงเท่านั้น
