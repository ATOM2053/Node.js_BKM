📜 กฎดิสคอมมู BKM

อ่านเถอะ ไม่งั้นเดี๋ยวโดนเตะแล้วงงว่าทำไม 🗿

  • 01・🤝 อย่าหาทำกับคนอื่น: คุยกันดี ๆ ได้ ไม่ต้องเปิดโหมดนักเลงใส่กัน ด่า เหยียด บูลลี่ คุกคาม หรือจงใจปั่นให้คนอื่นหัวร้อน = พักก่อนนะเพื่อน
  • 02・💬 อย่าสแปมจนแชทเป็นนรก: ส่งข้อความรัว ๆ, เมนชันไม่หยุด, กดอีโมจิเป็นร้อย = ใจเย็น ๆ นิ้วเอาไว้ใช้พรุ่งนี้ด้วย
  • 03・📢 อย่าเนียนโฆษณา: “แวะมาดิสเราได้นะครับ 🤭” ถ้าไม่ได้รับอนุญาต = โฆษณาอยู่ดีจ้า ติดต่อทีมงานก่อน
  • 04・🔞 อะไรไม่เหมาะสมก็เก็บไว้ที่บ้าน: ห้ามส่งสื่อลามกหรือเนื้อหาทางเพศที่โจ่งแจ้ง รวมถึงอะไรที่ทำให้คนเปิดแชทแล้วต้องรีบปิดหน้าจอหนี 😭
  • 05・🔐 ข้อมูลส่วนตัว = ห้ามยุ่ง: ข้อมูลส่วนตัวของคนอื่นไม่ใช่ของแจก อย่าเอาไปเผยแพร่ อย่าเอาไปขู่ และอย่าเอาไปเล่นสนุก
  • 06・🔥 ดราม่าได้ แต่อย่าเผาดิส: มีปัญหากันคุยกันดี ๆ อย่าลากทั้งเซิร์ฟมาร่วมสงคราม แชทนี้ไม่ใช่สนามรบครับพี่
  • 07・📂 อยู่ห้องไหนใช้ให้ถูก: มีห้องคุยเล่นก็ไปคุยเล่น มีห้องมีมก็ไปปล่อยมีม อย่าเอาเรื่อง “แมวที่บ้านผมไม่กินข้าว” ไปลงห้องประกาศ 💀
  • 08・🛑 เจออะไรแปลก ๆ แจ้งทีมงาน: เห็นคนทำผิดกฎ ไม่ต้องเปิดศึกเอง กดแจ้งทีมงาน แล้วนั่งจิบน้ำรออย่างสงบ 🧃
  • 09・👮 ทีมงานไม่ได้มีไว้ประดับเซิร์ฟ: ถ้าทีมงานเข้ามาเตือน ขอให้รับฟังกันดี ๆ มีข้อสงสัยหรือคิดว่าตัดสินไม่แฟร์ → คุยกันได้แบบมีเหตุผล
  • 10・⚖️ ทำผิด = มีบทลงโทษ: อาจเริ่มตั้งแต่เตือน → Timeout → Kick → Ban ขึ้นอยู่กับความหนักเบาของเรื่อง “แต่ผมไม่รู้กฎ” ไม่ใช่บัตร VIP กันโดนลงโทษนะ 🗿

กฎการโดนใบ BKM

บทลงโทษภายในตระกูล BLACK KINGDOM ทั้งหมด 18 ข้อ

1. สมาชิกต้องฟังคำสั่งจากหลีดรองหลีดผ่าฝืน ใบเหลือง🟨/ใบส้ม🟧
2. นำพาความเดือดร้อนมาให้ตระกูลโดยไม่รับผิดชอบ ใบแดง🟥/ใบดำ⬛
3. นำพาผู้อื่นหรือคนภายนอกเข้าดิสโดยไม่ได้อนุญาต ใบเหลือง🟨
4. นำสกินแก๊งไปขายหรือจำหน่ายให้ผู้อื่น ใบแดง🟥/ใบดำ⬛
5. เล่นโปรเล่นมอด ใบดำ⬛
6. ด่าเรื้อนไปด่าแก็งอื่น ใบส้ม🟧
7. ไม่เชื่อฟังผู้คุมสายสตอรี่ ใบเหลือง🟨/ใบส้ม🟧
8. ไม่มีความรับผิดชอบ ใบเหลือง🟨
9. สอบสวนแล้วให้การเท็จ ใบแดง🟥
10. แจ้งลาโดยสาเหตุไม่ชัดเจน ใบเหลือง🟨
11. ส่งลิ้งค์ดิสมั่ว ใบเหลือง🟨
12. ด่าบุพการี ใบส้ม🟧
13. ผ่าฝืนกดคลูดาวห์พบเจอสถานที่ต้องห้าม โดน×2 🚫
14. นำข้อมูลภายในแก็งไปเผยแพร่ ใบแดง🟥/ใบดำ⬛
15. ไม่จ่ายเงินแก๊ง ใบเหลือง🟨
16. เข้าร่วมกิจกรรมยึดคุก หรือกิจกรรมอื่นๆ หากรู้ว่าร่วมมือกับแก๊งอื่น โดนใบ 🟥🟥🟥❗
17. มีปัญหาหรือเรื้อนหรือทำให้ร้ายพันธมิตร โดนใบ ⚫⚫⚫❗❗❗
18. แก๊งมีโพเทคและคนในแก๊งทำโพเทคแตก ใบ🟡🟡🟡❗+เสียค่าโพเทค

กฎการเล่นกิจกรรมแก๊ง

ข้อบังคับในการลงเล่นกิจกรรม AirDrop, ยึดคุก Pawria Town และ วอยึดโซน

กฎแอร์ดรอป (เวลาเล่น: 13:00, 18:00, 21:00 น.)

  • ห้ามมีสตอรี่กันโดยเด็ดขาดในเวลากิจกรรม [ บังคับ ]
  • ห้าม Toxic หรือ บัพกันแรงเกินไป
  • สามารถใช้ AED ใน AirDrop ได้
  • สามารถใช้ Bandage ในการ Heal ตัวเองได้
  • ไม่สามารถใช้อีโมได้ เนื่องจากเป็นการเอาเปรียบ MB / มือถือ [ บังคับ ]
  • ห้ามใช้ MOD / โปรแกรมโกง / สิ่งที่จะทำให้ได้เปรียบฝั่งตรงข้าม [ โทษใบแดง / บังคับ ]
  • สามารถใช้เกราะได้ปกติ
  • ห้ามตีก่อน 5 นาทีเด็ดขาด!

กฎยึดคุก Pawria Town (เวลาเล่น: 20:00 น.)

  • 1. ต้องตีกันให้ตายจนเหลือเพียง 1 แก๊ง ถึงจะเก็บจุดยึดคุกได้ (ทำบัคเก็บ = ใบแดง / เก็บตอนผู้เล่นยังตายไม่หมด = ใบส้ม)
  • 2. ห้ามร่วมมือกับแก๊งอื่น (ใบส้มทั้งแก๊ง)
  • 3. ห้ามอีโม (ใบแดง)
  • 4. ห้ามนำเรื่องกิจกรรมมาเป็นสตอรี่ (ความแค้นส่วนตัวในกิจกรรม) (ใบเหลือง)
  • 5. ห้ามใส่สกินเด็ก, สกินตัวเล็ก (ใบส้ม)
  • 6. ห้าม Toxic หรือบัพกันแรงเกินไป (ใบแดง)
  • 7. ห้ามใช้มอด โปร ทำบัค (ใบแดง)
  • 8. ห้ามอุ้ม กักศพ
  • 9. ห้ามบู๊ด เปิดซาวด์ก่อกวน (ใบเหลือง)
  • 10. ห้ามดักจุดเกิด (ใบเหลือง)
  • 11. ห้ามใส่แฟชั่นเล่นกิจกรรม

กฎวอยึดโซน

  • ห้าม DB หรือ ขับรถชนในโซน (ใบเหลือง)
  • ห้ามตีนอกสถานที่ (ใบส้ม)
  • ห้ามอุ้มศพกักศพ (ใบส้ม)
  • ห้ามใส่สกินเด็กเล่นกิจกรรม (ใบส้ม)
  • ห้ามเล่นโปรมอด (ใบแดง)
  • ห้ามอีโม (ใบแดง)
  • ห้าม Toxic หรือบัพแรงเกินไป (ใบแดง)
📌 ข้อบังคับเพิ่มเติมสำหรับวอยึดโซน:
• การเล่นวอยึดโซนจะต้องต่อสู้ภายในวงเท่านั้น ห้ามออกจากวงเพื่อไปปั๊มยา, ชุบชีวิต หรือจะอุ้มเพื่อนไปชุบหรือทำกิจกรรมอื่นใด แล้วกลับเข้ามาวงใหม่
• ห้ามพันธมิตรกันหรือร่วมมือกันกับแก๊งอื่นในช่วงกิจกรรม
• หากไม่สามารถต่อสู้ต่อได้ หรือประสงค์จะถอนตัว ให้ขับรถออกจากพื้นที่นั้น เพื่อยอมแพ้
• ห้ามตีนอกบริเวณวงกิจกรรมเด็ดขาด ต้องตีกันในวงเท่านั้น
